# Strict CUDA 优化进度

这是新 CUDA 的专项重测，覆盖 3 个模型 × F32/F16/Q8 × 50 图，另有 150 图 Q8 F32-input。完整 CPU/CUDA/Vulkan 基线仍在上一级画廊。

**全模型原版 CUDA 逐位一致、全部后端 strict 更快仍为 open。** 算子通过不能替代全模型通过。

计时：原图解码到校准三元组；2 次预热、5 次重复；官方 Python 在每组模型前后独立测量。
