# Retained RA-4M validation subset

The suite is [manifest.json](../test_data/ra4m_50/manifest.json) and 50 original
images from the five validation shards of `maelic/RA-4M` revision
`64829d57318dc8b32ac3e029ac84fbb9834a7700`. Selection is deterministic diversity
and difficulty sampling. The 49,350,823,236-byte source snapshot was removed
after extraction; the retained originals total 3,562,723 bytes. Image hashes,
dimensions, relation endpoints and counts are verified by `compact_ra4m.py`.

| Coverage | Value |
|---|---|
| Sources | COCO 17, Objects365 17, Open Images 16 |
| Difficulty heuristic | hard 38, moderate 12 |
| Positive annotated relations | 803 |
| Object categories / predicate strings | 200 / 205 |

The difficulty label is a sampling heuristic, not a benchmark score. Inputs are
GT boxes, no masks, full released vocabulary, batch 1 and 448×448. Every model
uses all 50 images. Timings use two per-image warmups and five iterations, with
Python bracket passes around each model's native matrix. Loading/export is
excluded consistently. Exact recall and timing are included in the [complete report](summary/README.md),
and the [all-image visual gallery](gallery/index.html) replaces old smoke results.

Exact `(subject, object, predicate string)` recall is a local regression metric.
Macro recall weights each observed predicate equally. It cannot establish the
paper's six-axis OVS score, synonym calibration, precision or AP: GT is an
incomplete positive set and unmatched predictions are not negatives.

```sh
python3 cpp_ggml/scripts/compact_ra4m.py --verify-only
python3 cpp_ggml/scripts/run_alignment.py --run-id my-alignment --current
```
