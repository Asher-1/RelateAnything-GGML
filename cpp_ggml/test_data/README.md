# Test data

Run `python3 cpp_ggml/scripts/download_test_data.py` to fetch metadata for
RA-4M and public VG150, PSG and IndoorVG alternatives. Pass `--dataset
OWNER/NAME` to select one repository. `--allow-large` downloads the entire
selected source; RA-4M alone is about 49.35 GB. Files land under
`test_data/official/` by default.
Generated `.raio` and `.raoo` files are binary runtime fixtures and are ignored
from release packaging unless explicitly added.

The current checkout contains 50 original RA-4M validation images and full
per-image GT in `ra4m_50/`. `compact_ra4m.py` verifies hashes, dimensions,
relations, source quotas and exact image count. The 49.35 GB source download
was removed after verification. The retained images and GT manifest are included for reproducible evaluation;
the original source dataset terms still apply.
`../benchmarks/ra4m_verification.json` is historical proof that the initial
full snapshot matched its upstream file list. `maelic/OV-SGG-Bench` currently
returned HTTP 401 on the 2026-09-30 public API recheck (earlier 404); alternative public datasets are listed in
`../benchmarks/OFFICIAL_DATA.md` and this does not block the 50-image run.

Run `python3 cpp_ggml/scripts/audit_ra4m_validation.py` to scan the retained
50-image GT without decoding images. Run
`python3 cpp_ggml/scripts/visualize_ra4m_samples.py --device cuda` to generate
three reproducible source-corpus examples with all three official Python
checkpoints. Run `python3 cpp_ggml/scripts/benchmark_ra4m_50.py --device cuda`
for all 50 images. The current native full-model comparison is generated by
`benchmark_full_graph.py` and stored under `../benchmarks/full_graph/`.

`python_stage_trace.npz` is a local, generated set of official checkpoint
intermediate arrays for one retained image. Regenerate it with
`python3 cpp_ggml/scripts/trace_python_stages.py --device cuda`; its
shape/statistics inventory is `../benchmarks/python_stage_trace.json`.
